# Dreamer signal taxonomy

## Strong signals (prefer)

| Signal | Example |
|--------|---------|
| Recurrence | Same theme in ≥2 research notes or digests |
| Friction | Same failure / workaround mentioned twice |
| Fit | Matches local-inference, isolation, agents, markets/space |
| Compounding | Would become a skill, digest rule, or safer default |
| Operator ask | Jordan explicitly wants ideas in a domain |

## Weak signals (usually drop)

| Signal | Why drop |
|--------|----------|
| Single viral bookmark | No pattern yet |
| Vendor launch hype | No local leverage |
| Infra change without ask | Needs Jordan; not Dreamer's call |
| "Rewrite everything" | Unbounded; not a contract |

- Coder/skills = only after approval
